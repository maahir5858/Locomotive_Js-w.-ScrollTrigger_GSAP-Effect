# Locomotive.js with GSAP ScrollTrigger Project

## 🗣️ About

This is a **Locomotive.js** website integrated with the **GSAP ScrollTrigger plugin**. The project demonstrates smooth scroll-based animations and interactive effects that trigger as the user scrolls through the page. It's a side project created to practice advanced scrolling techniques and dynamic content animation using JavaScript, **Locomotive.js** for smooth scrolling, and **GSAP's ScrollTrigger** plugin for animation control.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- ***Locomotive.js***
- ***GSAP Library***
- ***ScrollTrigger Plugin***
